# Revanth HMS — Portfolio

Personal portfolio of Revanth HMS, a Java Full Stack Developer based in Bengaluru, India, showcasing web development and Generative AI projects.

**Live site** — https://YOUR-SITE-URL/

## Tech stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- AOS
- EmailJS
- WebGL

## Run locally

```sh
npm install
npm run dev
npm run build
```

The development server prints its local URL. The production build is generated in `dist/`.

## Environment variables

Configure these variables in a Git-ignored `.env.local` file for local development and in your hosting provider’s environment settings for deployment.

- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`

Restart the development server after changing the variables. When EmailJS is unconfigured, the contact form opens a draft in the visitor’s email app.
