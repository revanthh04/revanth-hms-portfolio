# My Portfolio

React 19 + Vite + Tailwind CSS 4 portfolio project.

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

Run `npm install` to install dependencies and `npm run dev` to start the development server.

Run `npm run lint` to check code and `npm run build` to create the production build.
